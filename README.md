List commands:

/sh help - show help (показать помощь)

/sh speedrunner <player> - set as speedrunner (назначить спидранером)

/sh hunter <player> - set as hunter (назначить охотником)

/sh remove <player> - remove player role (удалить роль игрока)

/sh list - list player roles (список ролей игроков)

/sh clear - clear all roles (удалить у всех роли)

/sh time <seconds> - set headstart time (время форы спидранерам)

/sh go - start the game (начать игру)

/sh nick on <player> - hide player nick (скрыть ник игрока)

/sh nick off <player> - show player nick (показать ник игрока)

/sh nick toggle [player] - toggle nick visibility (переключить видимость ника)

/sh nick on hunters - hide all hunters nicks (скрыть ники охотников)

/sh nick off hunters - show all hunters nicks (показать ники охотников)

/sh nick on speedrunners - hide all speedrunners nicks (скрыть ники спидранеров)
/sh nick off speedrunners - show all speedrunners nicks (показать ники спидранеров)
/sh nick toggle hunters - toggle all hunters nicks (переключить видимость ников охотников)
/sh nick toggle speedrunners - toggle all speedrunners nicks (переключить видимость ников спидранеров)
